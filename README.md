# Maincrafts Full Stack Internship - Task 1

This project is a full-stack submission for the Maincrafts Java Internship. It features a responsive landing page and a Spring Boot backend designed to handle contact form submissions.

## Features
- **Frontend**: Clean, minimalist UI built with HTML5 and CSS3.
- **Backend**: Java Spring Boot application with a REST Controller to process POST requests.
- **Integration**: Seamless form handling where user input is captured and logged in the console.

## Technologies Used
- Java
- Spring Boot
- HTML5 / CSS3
- Maven

## How to Run
1. Clone this repository: `git clone [your-repo-link]`
2. Import the project into your IDE (IntelliJ or VS Code).
3. Run the `DemoApplication.java` file.
4. Navigate to `http://localhost:8080/index.html` in your browser.
5. Fill out the form and check the IDE console for logs.
